# 📊 Recruitment Funnel Performance & Candidate Progress Analysis

## 🔍 Project Overview
This project presents an end-to-end **Recruitment Analytics Dashboard** built using Power BI. It provides insights into candidate journey, hiring performance, and recruitment efficiency.

---

## 🎯 Objectives
- Analyze recruitment funnel stages
- Track candidate progress across stages
- Identify drop-off points
- Evaluate hiring efficiency by department
- Measure source effectiveness

---

## 📈 Key Insights
- Total Applicants: 100
- Total Hired: 28
- Drop-off Rate: 36%
- Top Hiring Department: Sales
- Average Time to Hire: 6.29 days

---

## 📊 Dashboard Features

### 1️⃣ Candidate Details
- Applicant-level data
- Source, department, and status tracking

### 2️⃣ Recruitment Analysis
- Funnel visualization (Applications → Hired)
- Department-wise hiring performance
- Source contribution analysis

### 3️⃣ Recruitment Performance
- Drop-off rate by stage
- Monthly hiring trends
- Applications vs Hires comparison
